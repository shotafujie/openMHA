# OpenMHA Live

C++17・Qt Widgets・PortAudioによるリアルタイム音声処理GUIです．MATLABやWAVの準備は不要です．既存のopenMHAプラグインをアプリ内で直接ロードします．

## このMacで起動

Finderで `apps/live-audio/build/OpenMHALive.app` を開いてください．ターミナルからは，リポジトリのルートで次を実行できます．

```sh
open apps/live-audio/build/OpenMHALive.app
```

1. ヘッドホンを接続し，入力に使用するマイク，出力にヘッドホンを選びます．OS既定の入力がBlackHoleなどの仮想デバイスになっている場合は，実際のマイクへ変更してください．
2. 「開始」を押し，macOSから求められたらマイクアクセスを許可します．初期状態では出力をミュートしています．
3. 入力メーターの反応を確認し，「音を出す」にチェックを入れます．出力音量は初期値−20 dBから調整できます．スピーカーからマイクへの回り込みを避けるため，ヘッドホンで試してください．
4. 処理やデバイスを変更したら「設定を適用」を押します．処理中は短く停止して再開します．出力音量・ミュートだけは即時反映されます．終わったら「停止」を押してください．

音源を「テスト音 · 440 Hz」にすると，マイク許可なしで処理と出力を試せます．音声の録音・ファイル保存・ネットワーク送信は行いません．

## 処理

- ゲイン：−16〜+16 dB．
- ローパス：1次フィルターの周波数を80〜18000 Hzで設定．その後の試聴音量は独立です．
- コンプレッサ：`transducers` で振幅をPaに換算し，`dc_simple` で処理，振幅へ戻した後にゲインを適用．圧縮開始50 dB SPL，圧縮比1:1〜10:1，リミッター開始入力90 dB SPLです．校正値は左右・入出力共通の仮定値で，機器の実測校正ではありません．

入力は最大2チャンネルです．モノラル入力は内部の左右へ複製し，出力も最大2チャンネルです．1チャンネル出力の場合は左チャンネルを使用します．サンプルレートは48 kHzまたは44.1 kHz，ブロックサイズは128です．対応しないデバイス組み合わせはエラーを表示します．Bluetooth・別々の入出力クロックなどを含む全デバイス構成での動作保証はありません．

表示する遅延はPortAudioが報告する入力・出力レイテンシーの合計です．マイクから耳までの実測値ではなく，音源がテスト音の場合は出力レイテンシーのみです．バッファ警告数と処理ブロック数も表示します．出力は音量変更を平滑化し，デジタル振幅±0.95でクリップします．音圧を保証するリミッターではありません．

## ビルド

openMHAを先に `.local` へビルド・インストールします．手順は [C++開発ガイド](../../docs/CPP_DEVELOPMENT_ja.md) を参照してください．Qt 6.5以降（Widgets），PortAudio，CMake 3.21以降が必要です．macOSでの追加依存関係は次のとおりです．

```sh
brew install qtbase portaudio
cmake -S apps/live-audio -B apps/live-audio/build -DCMAKE_PREFIX_PATH=/opt/homebrew
cmake --build apps/live-audio/build -j4
ctest --test-dir apps/live-audio/build --output-on-failure
```

Intel Macや別の配置では `CMAKE_PREFIX_PATH` を依存ライブラリのprefixに変更します．openMHAの配置は `-DOPENMHA_ROOT=/absolute/path/to/prefix` で指定できます．環境変数 `MHA_LIBRARY_PATH` があればプラグイン検索に優先使用します．

Qt・PortAudioを使う共通ソースでWindows／Linuxを対象にしていますが，ビルドと実機確認はmacOSのみです．他OSでは，各依存ライブラリを同じCPU・互換性のあるC++ツールチェーンでビルドし，CMakeの検索パスを指定してください．特にWindowsのopenMHAとQtのC++ ABIを揃える必要があります．現時点の `.app` はこのMacの `.local` とHomebrewに依存する開発用です．依存ライブラリ同梱，署名・公証，Windowsインストーラー等は未対応です．

## 実装

`main.cpp` が画面，権限要求，設定操作，レベルメーターを担当します．`engine.cpp` がPortAudioストリームとopenMHAプラグインのライフサイクルを管理します．設定の解析・プラグイン生成は音声ストリーム停止中に行い，音声コールバック内では事前確保したバッファで処理します．音量とメーター値はアトミック変数で受け渡します．プラグイン例外や想定外のブロック長は無音化して停止します．厳密なハードリアルタイム性を保証するものではありません．

設計時に確認した一次資料：[PortAudioのコールバック制約](https://portaudio.com/docs/v19-doxydocs/writing_a_callback.html)，[Qtの権限API](https://doc.qt.io/qt-6/permissions.html)．
