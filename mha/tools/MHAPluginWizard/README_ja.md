# MHAPlugin Wizard

[原文](README.txt)の日本語訳です．Qt Creator 3.5.1用のウィザードについての説明です．現行Qt Creatorでの動作は未確認です．

`MHAPluginWizard` ディレクトリ全体を次のいずれかへコピーします．

- Qt／Qt Creatorインストール先の `share/qtcreator/templates/wizards`
- ユーザー設定フォルダ `$HOME/.config/QtProject/qtcreator/templates/wizards`
- Windowsの `%APPDATA%\QtProject\qtcreator\templates\wizards`

Qt Creatorを再起動し，File → New File or Projectを開きます．表示されたMHA ProjectsカテゴリからMHA Plugin (two classes)を選び，Chooseを押します．プラグイン名と保存先，Kitを指定し，Detailsページでテンプレート変数を入力します．最後に概要ページでFinishを押します．
