## 1. はじめに

HörTech Open Master Hearing Aid（openMHA）はアルゴリズムの開発と評価のためのソフトウェアプラットフォームです。アルゴリズム評価の特定の側面では、テストセットアップの正しいキャリブレーションが必要な場合があります。

openMHA はソフトウェアプラットフォームであるため、ハードウェア（補聴器筐体、マイク、レシーバーなど）は含まれていません。openMHA のユーザーは、装用者の耳で音を拾い、音を生成するための適切なハードウェアを補完することが期待されます。その際、ソフトウェアを正しく設定してシステムをキャリブレーションするという課題に直面します。

このガイドは、openMHA の著者とユーザーがセットアップを正しくキャリブレーションするために使用しているベストプラクティスの集まりです。openMHA に新しい手順を追加したり、キャリブレーションの分野でユーザーからの貢献を受けたりするにつれて、このガイドを拡充していきます。

openMHA のユーザーは、キャリブレーションが複雑なトピックであることを認識してください。正確な測定を行うためには、専門的で特殊な音響測定機器が必要であり、その機器の使い方を理解する必要があります。市販の補聴器のキャリブレーション方法を理解していることが、このガイドを使用するための前提条件です。Harvey Dillon 著 "Hearing Aids" の第2版（2012年）第4章にこのトピックの適切な解説があります。

ここで紹介する手順にエラーがないことを保証することはできません。何か誤りを発見した場合は、例えば github プロジェクトに issue を提出するなどして、openMHA プロジェクトに連絡してください。ドキュメントと提供するツールの改善に最善を尽くします。

## 2. カスタム補聴器出力のキャリブレーション

このセクションでは、カスタム補聴器出力ハードウェアの周波数応答を測定する方法と、この周波数応答を使用してデバイスの出力をキャリブレーションする方法について説明します。

### 2.1 カスタムハードウェアのキャリブレーションに関する考慮事項

補聴器レシーバーは通常、低インピーダンスで非フラットな周波数応答を持っています。補聴器レシーバーをコンピュータのサウンドカードの出力に接続する場合、サウンドカードが実際にレシーバーを駆動できること、つまり電圧降下なしに必要な電流を供給できることを確認する必要があります。そうでなければ、深刻な非線形性が生じます。出力ハードウェアを駆動するための適切なアンプの使用を検討してください。

測定マイクを補聴器レシーバーに接続するために、適切な音響カプラーを使用する必要があります。カプラーは実際の耳道に類似した機械的特性をシミュレートします。カプラーは測定マイクのキャリブレーション方法にも影響します。詳細は Dillon と測定機器のマニュアルを参照してください。

カスタム補聴器ハードウェアをキャリブレーションする場合、常に個々のサウンドカード、使用するアンプ、補聴器レシーバーの組み合わせからなる完全な出力チェーンをキャリブレーションすることになります。

補聴器は自由音場の音圧レベルではなく、耳道内の音圧レベルを生成する必要があります。このため、openMHA の出力キャリブレーションには Real-Ear-Unaided-Gain（REUG）も適用することを推奨します。REUG の説明については Dillon を参照してください。

補聴器デバイスのキャリブレーションでは、平均的な耳に対するキャリブレーションで良いか、特定の被験者の個別の耳に対するキャリブレーションが必要かを選択する必要があります。以下のテキストでは、平均キャリブレーション方法のみを説明します。これは将来変更される可能性があります。

キャリブレーションには信頼性の高い音響レベル測定が必要です。これは静かな環境でのみ達成できます。すべての音響測定は、適切な防音室または同様の環境で行ってください。キャリブレーション機器がサポートしている場合、非常に低い周波数（例: 20 Hz 未満）をフィルタリングすることを検討してください。測定レベルの変動に気付いた場合（建物の他の階のドアや外の交通によるもの）、より良い遮音の場所に移動するか、オフピーク時間に行うことを検討してください。

避けられないノイズの影響を最小限にするため、音響キャリブレーションは約 80 dB の比較的高い音圧レベルで行われます。カスタム出力ハードウェアでこれらのレベルを達成できない場合、より低い音圧レベルを測定するよりも、出力ハードウェアの変更を検討すべきです。

MHA を使用してテスト音を生成し、その音響レベルを測定します。高周波のテスト音を生成する場合、サウンドカードがナイキスト周波数以下の周波数にも影響するアンチエイリアシング用ローパスフィルタを適用することに注意してください。これは比較的低いオーディオサンプリングレートに対してシステムをキャリブレーションする場合に問題になることがあります。例えば、サウンドカードで 16 kHz のサンプリングレートを使用する場合、8 kHz での音圧レベル測定は避けるべきであり、6 kHz で取得した測定値をより高いサウンドカードサンプリングレートに再利用すべきではありません。

キャリブレーションプロセスは実用的な限界にぶつかり、妥協が必要になるでしょう。例えば、補聴器レシーバーは通常、低周波では同じ電圧で大幅に弱い音圧レベルを生成します。正確なキャリブレーションには、補聴器出力ハードウェアの周波数応答を反転するフィルタが必要です。この場合、低周波で高いゲインで増幅する必要があります。しかし、低周波で十分に高いゲインを使用すると、出力信号振幅がサウンドカードのダイナミックレンジを超えてしまいます。サウンドカードの最大振幅を超える信号を生成することはできないため、キャリブレーションフィルタ適用後に信号を制限する必要があります。この制限は可聴なアーティファクトを引き起こします。

これらの状況を避けるために、通常は伝送スペクトルの境界で過度に高い増幅を避け、これらの周波数領域では補聴器信号処理アルゴリズムが意図するよりも出力レベルが低いことを受け入れる方が良い選択です。

### 2.2 IEC 711 カプラーを使用した周波数応答の測定

ここでは、IEC 60 711 に準拠したカプラーを使用して、カスタム補聴器出力ハードウェアの周波数応答を openMHA で測定する方法を説明します。2cc カプラーと比較して、IEC 711 カプラーには、平均的な耳に対して Real-Ear-to-Coupler-Difference（RECD）が十分に小さく、平均的な耳のキャリブレーション測定時に考慮する必要がないという利点があります。

IEC 711 カプラーで測定を行うために測定機器を組み立て、キャリブレーションしてください。機器メーカーのマニュアルを参照してください。一部のキャリブレーターデバイスでは、IEC 711 用に機器をキャリブレーションする際に補正係数を考慮する必要があることに注意してください。

機器がキャリブレーションされたら、openMHA の助けを借りて出力ハードウェアの周波数応答を測定できます:

1. キャリブレーションを行うコンピュータに openMHA をインストールします（README.md 参照）。

2. 測定を制御するために Octave/Matlab ツールを使用します。準備として:
   - openMHA 環境変数を設定したシェルから Octave/Matlab を起動します。
   - ディレクトリ `mha/tools/mfiles` に移動します。

3. 後で openMHA で使用するのと同じサンプリングレートで JACK サウンドサーバーを起動します。

4. カスタム補聴器出力ハードウェアを目的のサウンドカード出力チャンネルと測定機器に接続します。

5. openMHA に付属の Octave/Matlab 関数 `measure_fresponse` を使用して周波数応答を測定します:
   - 以下のパラメータでこの関数を呼び出します:
     1. JACK でのサウンドカードチャンネル名（例: `'system:playback_1'`）
     2. JACK サーバーのサンプリングレート（Hz）
   - 関数は以下のフィールドを含む構造体を返します:
     - **Frequencies** — テスト音の周波数のベクトル（Hz）
     - **dBFSfor80dB** — 音響レベルが 80 dB だった場合のサウンドカードの dB re full scale（dB FS）での対応するレベルのベクトル
     - **REUGdB** — REUG を補償するための推奨補正ゲインのベクトル（dB）
     - **correctionsdB** — 対応する補正ゲインのベクトル（初期値はすべて 0）
   - 例: `response = measure_fresponse('system:playback_1', 48000);`
   - 関数は MHA を起動し、テスト音の出力を開始します。
   - 出力に接続された測定機器が各テスト音の音響レベルを測定します。
   - 目標は、テスト音が 80 dB の音響レベルを生成するように出力レベルを調整することです。
   - 音響レベルが 80 dB と異なる場合、80 dB に到達するために必要な差分を入力してレベルを調整します。
   - セットアップが 80 dB の音響出力レベルを生成するまで補正を繰り返します。
   - 80 dB に到達したら、補正値 0 を入力して次のテスト音に進みます。

これで Octave/Matlab の構造体にセットアップの周波数応答が格納されました。Octave/Matlab で利用可能なすべてのツールを使用して、この構造体の測定された周波数応答を検査・変更してから、MHA のキャリブレーションに使用できます。

周波数応答をプロットするために使用できる Octave/Matlab 関数 `plot_fresponse` を提供しています。プロットは出力ハードウェアの MHA をキャリブレーションするために必要なフィルタの周波数応答を表示します。このフィルタは出力ハードウェアの周波数応答を反転し、REUG を適用するためのゲインを追加します。

このフィルタが示す全体的なダイナミクスが十分に小さく、平均化された周波数応答を完全に補償するキャリブレーションフィルタをそのまま適用するか、高周波や低周波での過度のゲインを避けるために Octave/Matlab の周波数応答構造体の `correctionsdB` ベクトルを変更して補正ゲインを導入するかを決定する必要があります。

### 2.3 測定された周波数応答を使用した補聴器出力デバイスのキャリブレーション

openMHA プラグイン `transducers` は入出力のキャリブレーションに使用されます。`transducers` は FIR フィルタパラメータとピークレベルで設定でき、補聴器マイクとレシーバーの周波数応答を補償します。

この機能を使用するには、既に `transducers` プラグインを含む openMHA 設定を選択するか、`transducers` を含む新しい設定を作成してください。

キャリブレーションフィルタの周波数応答に満足したら、周波数応答構造体を openMHA 設定で使用できるフィルタ係数セットとピークレベルに変換できます。Octave/Matlab 関数 `fresponse_to_cfg` を使用して、周波数応答構造体を openMHA 設定で使用できるテキスト文字列に変換できます。

関数 `fresponse_to_cfg` は、openMHA プラグイン `transducers` の `peaklevel` と `fir` 設定変数の値を出力します。

これらの値を設定ファイルの `transducers` 設定に挿入できます。出力される省略記号（`...`）を削除し、余分なセミコロンを削除してください。これらは複数の出力チャンネルがある場合のために `fresponse_to_cfg` によって出力されます。ピークレベルと FIR フィルタ係数を、測定されたハードウェアに対応する正しい出力チャンネルに割り当てる必要があります。

### 追加のツール

1. 計算能力の低いターゲットデバイスの場合、プラグイン `transducers` の FIR フィルタ（時間領域で計算）の使用は計算コストが高すぎる場合があります。そのようなデバイスで動作する openMHA 設定の代替として、周波数領域の `equalize` プラグインで周波数応答を調整することが可能です。このルートを取る場合は、Octave/Matlab 関数 `fresponse_to_eq` の使用を検討してください。キャリブレーション目的で使用する前に、必ずこの関数を検査してください。

2. ポータブル補聴ラボ（PHL）のキャリブレーションには、openMHA の[サンプル 22](https://github.com/HoerTech-gGmbH/openMHA/tree/master/examples/22-phl-calibration)のアプリケーションノートを検討してください。

### 2.4 キャリブレーションのテスト

キャリブレーションのテストは極めて重要です。測定したキャリブレーション値でシンプルな openMHA を設定し、sine プラグインを挿入して、異なる周波数と異なるレベルのサイン波を再生してください。

openMHA の `examples` ディレクトリに適切な設定ファイルがあります。`test-calibration` サブディレクトリの設定ファイルを使用し、特定のキャリブレーション値を含むように変更してください。

設定は以下で起動できます:

```
mha ?read:test-calibration.cfg cmd=start
```

設定ファイルのサイン波周波数を変更して `mha.sine.f` の異なる値で MHA を繰り返し起動するか、ネットワークまたは Octave/Matlab ベースのツールを使用して実行中の MHA でこの値を変更できます。

測定周波数でサイン波を再生する際、測定機器で出力レベルを確認してください。80 dB のサイン波の出力レベルが 80 dB + REUG(f) + correction(f) として測定されることが期待されます。

数 dB までの差異は予想されます。スペクトル全体にわたって、差異が期待より高い出力レベルと低い出力レベルに均等に分布していることを確認してください。
