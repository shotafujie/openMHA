# MHA カーネル

> この文書は [MHA_kernel.tex](MHA_kernel.tex) の日本語訳です。

## 概要

MHA カーネルは、MHA 内の信号フロー管理と MHA プラグイン（処理ブロック）間の通信を担当します。カーネルはフレームワークアプリケーションによってロードおよび制御されます。処理プラグインは処理チェーンに挿入できます。複雑な設定間の切り替えが必要な場合は、複数のチェーンを設定できます。非アクティブな処理チェーンは、切り替えノイズを低減するため、または純粋な信号分析のためにオプションで計算できます。時間領域（波形）と周波数領域（STFT）の処理がサポートされています。MHA プラグインは単一のドメインで処理するか、ドメイン変換（例: FFT）として処理できます。

MHA カーネルはマルチチャンネル環境を提供します。任意の数の入出力チャンネルを設定できます（ただし、一部の標準的な補聴器アルゴリズムは2チャンネルでのみ意味があります）。プラグインでのダウンミキシングとアップミキシングが可能です。これはマイクアレイの処理に非常に関連があります。現時点では、マルチチャンネル処理は openMHA フレームワークでのみ利用可能で、Windows バージョンは2チャンネルに制限されています。openMHA フレームワークはオプションで、すべての信号処理チェーン出力のモニタリングを提供します。

## MHA カーネルの設定変数

| 変数 | 説明 |
|---|---|
| `disable_inactive` | 非アクティブなチェーンを無効にします。`yes` に設定すると、選択されたチェーンのみが計算されます。 |
| `chains` | 設定される信号処理チェーンのリスト。各エントリはサブパーサーとして表示され、アルゴリズムの設定を含むチェーン固有の設定を保持します。 |
| `chain` | 選択されたチェーンの名前。この変数を設定すると、以前に設定されたチェーンの1つが選択されます。 |
| `chainname.inputdomain` | チェーンの最初のプラグインに渡されるドメイン（`waveform` または `spectrum`）。 |
| `chainname.algos` | `chainname` が変数 `chains` のエントリであると仮定すると、これはこのチェーンで実行するアルゴリズムのリストです。この変数の各エントリは MHA プラグインのベース名です。プラグイン設定は `chainname` のサブパーサーとして表示されます。`basename:parsername` と明示的に指定しない限り、プラグインのベース名がサブパーサー名として使用されます。これは1つのチェーンで同じアルゴリズムの複数インスタンスを使用する場合に特に関連があります。このリストのアルゴリズムの順序が処理順序を決定します（左から右へ）。 |
| `fftname` | FFT ライブラリの名前（拡張子なし）。例: `wave2spec`。 |
| `ifftname` | 逆 FFT ライブラリの名前（拡張子なし）。例: `spec2wave`。 |
| `fft` | FFT プラグインの設定を含むサブパーサー。 |
| `ifft` | 逆 FFT プラグインの設定を含むサブパーサー。 |
