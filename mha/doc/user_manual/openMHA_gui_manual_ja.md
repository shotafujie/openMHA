# MATLAB/Octave グラフィカルユーザーインターフェース制御マニュアル

> [English version (LaTeX)](openMHA_gui_manual.tex)

## はじめに

HörTech Open Master Hearing Aid（openMHA）はアルゴリズム開発・評価プラットフォームです。リアルタイムシステムは補聴器デバイスとして動作するように設定できます。プログラム「mhacontrol」は制御画面とフィッティングインターフェースを提供します。このインターフェースは、基盤となるアルゴリズムの技術的な知識なしに使用できるよう設計されています。

このマニュアルでは、制御画面のダイアログと典型的なワークフローについて説明します。

## mhacontrol の起動

制御画面「mhacontrol」は MATLAB/Octave アプリケーションです。

MHA のインスタンスが既に起動していることを前提とします（詳細は README.md およびアプリケーションマニュアルを参照）。制御画面を起動するには、MATLAB/Octave を起動し、アプリケーションファイルのあるディレクトリに移動して、以下を入力します:

```
mhacontrol hostname
```

`hostname` は MHA のホスト名または IP アドレスです。MHA が MATLAB/Octave と同じホスト上で実行されている場合、ホスト名は省略できます。

MHA と MATLAB/Octave が異なるホスト上で実行されている場合は、ファイアウォールがポート 33337（または実際の MHA 設定で使用するポート）へのアクセスを許可していること、およびリモートホスト上の MHA が適切なネットワークデバイスでリッスンしていること（例: `mha -i 0.0.0.0`）を確認してください。MHA と mhacontrol 間には TCP ネットワーク接続が必要です。

**注意**: 制御ツールは MHA 設定ファイルの多くの値を mhacontrol の設定に格納された値で上書きします。これは主にクライアントデータ（ダイナミックコンプレッションの設定やファインチューニング）、およびキャリブレーションパラメータに影響します。MHAIOJack オーディオバックエンドを使用する場合、JACK 接続が制御画面によって変更される場合があります。

## ダイアログ

### メイン画面「mhacontrol」

メイン画面には、GUI が現在提供するすべての制御アプリケーションのボタンが含まれています。

右上エリアの「Actions」パネルには、よく使用される操作のスターターボタンがあります:
- **Fitting**: ダイナミックコンプレッションが利用可能な場合、フィッティングインターフェースを開きます
- **Levels**: レベルメーターを開きます

「Actions」パネルの下には「Administration」パネルがあり、MHA セットアップのメンテナンスに必要な操作のスターターボタンがあります:
- **Advanced control**: 汎用 MHA 設定ブラウザを開きます

### クライアント選択とフィッティング

#### クライアントデータベース

mhacontrol ソフトウェアには、クライアント管理用のシンプルなデータベースが含まれています。クライアントエントリは、クライアントデータベースダイアログで作成・変更できます。

クライアントエントリは、姓名、生年月日、一意のクライアント ID、および任意の数のオージオグラムで構成されます。左上パネルに既存のクライアントのリストが表示されます。リスト項目をシングルクリックして、オージオグラムエントリの編集対象を選択できます。「New client」「Edit client」ボタンでクライアントデータの入力・編集ができます。

ダイアログの右側でオージオグラムデータを管理できます。利用可能なオージオグラムが右上パネルにリストされます。新しいオージオグラムはオージオグラムデータの手動入力で作成できます（「Edit」ボタン）。選択したオージオグラムは「Print」ボタンで印刷できます。

#### オージオグラムエディタ

オージオグラムエディタでオージオグラムを手動で編集できます。ダイアログの上半分で、右耳と左耳の聴力閾値と不快レベルを入力できます。周波数をスキップするには 'inf' または 'nan' の値を入力します。左下にオージオグラム ID を入力でき、「Finish」ボタンでエディタを閉じます。現在のオージオグラムはダイアログの右下に表示されます。

#### フィッティングダイアログ

「OK」を押すとフィッティングダイアログが開きます。3つの列に分かれています:

**中央列**: ゲイン処方ルールの選択とファーストフィットの作成のための制御要素。下部にはプリセット管理ボックスがあります。プリセットには、ゲイン処方ルールとファインチューニングを含む、特定のクライアントとアルゴリズムのすべての設定が含まれます。

**左右の列**: 右耳と左耳の耳別設定。グラフには3つの異なるレベルでの LTASS（長期平均音声スペクトル）の公称ターゲットレベルが太い実線で表示され、1/3オクターブ帯域で計算されます。細い破線は対応する入力レベルを示します。影付き領域は ISO-226 正常聴力閾値（灰色）と選択された被験者の閾値（緑）を示します。

グラフの下にはファインチューニングの制御があります: ドロップダウンメニューで `gain` または `maxgain` を選択して、周波数帯域ごとの追加ゲインとゲイン制限を設定できます。

ファーストフィットを作成するには:
1. リストから適切なゲイン処方ルールを選択
2. 片耳コンプレッサの場合はフィッティングする耳を選択（選択はシグナルルーティングに影響しません）
3. 「Create First Fit」ボタンを押す

ファーストフィットは MHA にアップロードされ、プリセットリストに保存されます。ファインチューニングパラメータはデフォルト値に設定されます。ファーストフィットはファインチューニングされたプリセットで上書きされません。別のオージオグラムを選択した後に新しいファーストフィットを作成すると、同じゲインルールの以前のファーストフィットは上書きされます。

#### 商用フィッティングルールの使用

MHA のダイナミックコンプレッサは商用処方ルールでフィッティングできます。現在利用可能なのは:
- **DSLmio5** (https://www.dslio.com/) — University of Western Ontario 提供
- **NAL-NL2** (https://www.nal.gov.au) — National Acoustics Laboratory of Australia 提供

これらのルールを実装するソフトウェアライブラリは、それぞれの提供元から入手する必要があります。MHA のフィッティングダイアログは、これらのライブラリのラッパーを呼び出してフィッティング結果を取得します。法的理由により、これらのラッパーは MHA の一部として配布されず、オプションの追加パッケージとしてインストールする必要があります。入手方法については MHA の GitHub リポジトリ (https://github.com/HoerTech-gGmbH/openMHA) の README.md を参照してください。

### レベルメーター

レベルメーターには2つの領域があります:
- **上部パネル**: 入力と出力の広帯域レベルを表示
- **下部**: RMS レベル平均化の時定数を調整可能（広帯域レベルメーターのみ）

### アドバンスト制御

MHA への汎用パラメータ制御インターフェースが利用可能です。このインターフェースの説明は MHA マニュアルに記載されています。
