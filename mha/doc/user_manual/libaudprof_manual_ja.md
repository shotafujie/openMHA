# 聴覚プロファイルライブラリ 'libaudprof'

> [English version (LaTeX)](libaudprof_manual.tex)

## はじめに

MHA は聴覚プロファイルに基づくフィッティングの概念を使用します。聴覚プロファイルとは、聴覚障害に関連する臨床データの集合です。現在使用されている構成要素は、気導・骨導聴力閾値、不快閾値、カテゴリカルラウドネススケーリングデータです。ほとんどのフィッティングルールは聴力閾値のみを利用し、ラウドネススケーリングデータを使用するものは少数ですが、基盤となるライブラリ関数はより多くのパラメータへの拡張手段を提供しています。

通常、フィッティングはグラフィカルインターフェース `mhacontrol` を通じて制御されます。このドキュメントでは、聴覚プロファイルデータベースから手動でプロファイルを選択し、MHA インスタンスにフィッティングをアップロードする方法を説明します。

## 聴覚プロファイルデータベースへのアクセス

MHA の聴覚プロファイルは `audprofdb.mat` という MATLAB 形式のファイルに格納されています。このデータベースへのグラフィカルインターフェースは MATLAB プログラム `clientdb` です。

聴覚プロファイルデータベースに直接アクセスするには、MATLAB ライブラリ `libaudprof` を使用して関数ハンドルの構造体を取得します:

```matlab
h = libaudprof();
```

サブ関数（例: `db_load`）のヘルプを取得するには:

```matlab
h.help.db_load()
```

クライアント ID 'TT123456' の聴覚プロファイル 'slope' を読み込む場合:

```matlab
cDB = h.db_load();
sClientID = 'TT123456';
sAudID = 'slope';
sAud = h.audprof_get( sClientID, sAudID, cDB );
```

すべての聴覚プロファイルを読み込むショートカット、およびリストの最後のプロファイルのみを読み込む方法:

```matlab
csAud = h.audprof_getall( sClientID );
sAud = csAud{end};
```

ここではデータベースが自動的に読み込まれます。

## XLS ファイルからのインポート

気導閾値を XLS シートからインポートするには:

```matlab
xlsname = 'myaud.xls';
h.db_xlsimport( xlsname );
% インポートデータの確認:
clientdb();
```

XLS ファイルは特定のフォーマットに従う必要があります:
- 最初の行はヘッダー行として解釈されます
- セル A1 は任意のテキストを含められます
- セル B1, C1, D1 等は側と周波数を文字列で指定する必要があります（例: 「l125」）
- フィールドは大文字小文字を区別しません。スペースを含むことができます
- 周波数は Hz 単位で指定します
- 側の識別子は 'l' または 'r' です
- 最初の列はクライアント ID を含む必要があります（インポート時に大文字に変換されます）
- 聴覚プロファイル ID は XLS ファイル名に設定されます
- データベースに既存の同一 ID・クライアント ID のプロファイルは上書きされます

## MHA へのフィッティングのアップロード

実行中の MHA（'running' または 'prepared' 状態）にフィッティングをアップロードするには、`libmultifit` ライブラリの関数を使用します:

```matlab
hMF = libmultifit();
sGainrule = 'NALRP';
sSide = 'lr';
csPlugs = hMF.uploadallfirstfit( mha, sGainrule, sAud, sSide );
```

両耳フィッティングの場合、側の文字列は 'lr' にする必要があります。片耳のみフィッティングする場合は 'l' または 'r' を選択してください。

聴覚プロファイルに Inf または NaN の値が含まれている場合、補聴器フィッティングの作成前に除去する必要があります:

```matlab
sAud = h.audprof_cleanup( sAud );
```
