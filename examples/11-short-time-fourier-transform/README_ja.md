# 11-short-time-fourier-transform: 短時間フーリエ変換

> [English version](README.txt)

多くの補聴器アルゴリズムはスペクトル領域で動作し、信号処理を行うために短時間フーリエ変換（STFT）信号を必要とします。

MHA は時間領域信号を STFT 信号に変換し、またその逆変換を行う専用プラグインを提供しています。最も一般的に使用されるのは `overlapadd` プラグインです。当サンプルディレクトリの多くの設定ファイルでこのプラグインが使われています。実際の使用例については各設定ファイルを参照してください。`overlapadd` の手順の説明については、プラグインドキュメント PDF を参照してください。

`overlapadd` プラグインは、STFT 信号が必要なほとんどのユースケースで推奨されます。時間領域信号から STFT 信号への変換、STFT 領域での信号処理を別のプラグインに実行させ、信号を時間領域に戻す変換を一括して行います。

一部のユースケースでは、順方向と逆方向の変換を別々のプラグインで行いたい場合があります。これは例えば `wave2spec` と `spec2wave` プラグインで可能です。このディレクトリにはこれらのプラグインの使用を実演するシンプルな設定ファイルが含まれています。
