# 29-python-examples: Python による openMHA 通信

> [English version](README.txt)

このサンプルでは、Python を使用した openMHA との基本的な通信方法を示しています。変数の値を設定・取得・表示し、cfg ファイルを読み込みます。

## 使い方

1. ターミナルを開き、`openMHA/examples/00-gain/` ディレクトリに移動
2. `mha` と入力して openMHA インスタンスを起動
3. 別のターミナルを開き、`openMHA/examples/29-python-examples/` ディレクトリに移動
4. `python3 basic_mha_communication.py` を実行
