# 12-ac-to-lsl: AC 変数から LSL ストリームへ

> [English version](README.txt)

ac2lsl プラグインの最小サンプルです。2つのパートで構成されています:

**設定ファイル `ac2lsl.cfg`**: MHA に `chirp.wav` を処理させ、処理チェーンに `rmslevel`、`save_wave`、`ac2lsl` プラグインを含めます。`rmslevel` と `save_wave` は複数の AC 変数を AC 空間に追加し、`ac2lsl` プラグインによってネットワーク上に LSL ストリームアウトレットとして自動的に配信されます。動作の観察を容易にするため、IO ライブラリは start コマンドごとに1バッファを処理するように設定されています。

**ソースファイル `receive_lsl.cpp`**: Makefile でコンパイルする必要があります。生成される実行ファイルは、LSL ストリームの受信とアンパックの最小サンプルです。コマンドライン引数で指定された LSL ストリームを開くか、名前が指定されない場合は利用可能なストリームを一覧表示し、最初のストリームを開きます。

このサンプルの各パートは、同一コンピュータ上でも異なるコンピュータ上でも実行できます。
