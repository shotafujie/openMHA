# 聴覚損失シミュレーションの使用例

## 概要

この例はopenMHA用の聴覚損失（聴覚障害）シミュレーターHSIMです．前リリースの実装を拡張し，基本構造，低遅延のリアルタイム処理，openMHAフレームワークとの統合を維持しながら，設定の柔軟性と使いやすさを高めています．パラメーターの計算・設定・変更・描画を行うMATLAB／Octave関数も含まれます．

- `cfg`：3つの設定ファイル `HSIM_*.cfg`
- Linuxシェルスクリプト `run_HSIM_*.sh` とWindowsバッチファイル `run_HSIM_*.cmd`：各3つ
- `mfiles`：`plot_HSIM_parameters.m` と `set_HSIM_parameters_*.m`，計4関数
- `soundfiles`：入力例 `HSIM_in.wav`

| 設定 | 処理 |
| --- | --- |
| `cfg/HSIM_live.cfg` | リアルタイム入力 |
| `cfg/HSIM_files.cfg` | ファイルからファイル |
| `cfg/HSIM_files_live.cfg` | 音声ファイルをループ再生してリアルタイム処理 |

既定値はBisgaardら（2010）のN1型，すなわち非常に軽度の平坦／緩やかな傾斜型の聴覚損失を再現します．文献に基づく簡略化した仮定を用い，ラウドネス成長曲線の変化と時間・周波数分解能の低下もモデル化します．多数のパラメーターを手動または付属ツールのプリセットで調整できます．

## 前提条件

ファイル処理用設定は，付属の入力音声からそのまま出力を生成できるよう作られています．別の音声ファイルも指定できます．リアルタイムのマイク入力・ループ再生には，正しく設定されたJACK Audio Connection Kit（QjackCtlを含む）と，JACKとサンプルレート・バッファサイズを揃えたオーディオインターフェースが必要です．詳細は各設定ファイルのコメントを参照してください．

正しく柔軟かつ安定して利用するため，次にも注意してください．

- 入力 `calib_in.peaklevel` と出力 `calib_out.peaklevel` の校正が必要です．レベル依存処理，特にダイナミックレンジ拡張の動作と，聴覚損失による減衰の再現性に関わります．既定の校正値を使うファイル処理・ループ再生では，付属ツールから入力の絶対音圧レベルを指定できるため，入力校正は必ずしも必要ではありません．詳細は校正マニュアルを参照してください．
- パラメーターの設定・変更・描画にはMATLABまたはOctaveの導入を強く推奨します．設定ファイルや実行中のopenMHAへ直接設定することも可能ですが，通常は手間がかかります．全関数は両方で動作しますが，一部のアルゴリズムではMATLABの方が大幅に高速です．
- 付属関数はガンマトーンツールボックス（Hohmann，2002；Hohmann & Herzke，2007）に依存します．ダウンロード後，MATLAB／Octaveの検索パスへ追加してください．openMHA本体の `mfiles` ディレクトリも検索パスへ追加する必要があります．
- Windowsでリアルタイム処理する場合は，十分な計算資源が継続的に割り当てられるようにしてください．システムによっては電源設定でプロセッサの最小状態を一時的に100%へ設定する必要があります．

マイク信号をリアルタイム処理する場合，直接音がヘッドホンを通して聞こえるため，意味のあるシミュレーションには通常，話者と聴取者を別室に配置する必要があります．

## 使用方法

左右の耳に対応するステレオ信号を扱います．入力はステレオ音声ファイルまたは2本のマイクです．原文ではLinuxとWindowsでの検証が報告されています．ディレクトリ全体を書き込み可能な場所へコピーすることを推奨します．

1. リアルタイム処理の場合は，適切なプリセットでQjackCtlを起動します．
2. openMHAを対話モードで起動し，対応する設定を読み込みます．付属の起動スクリプトを利用できます．
3. 必要に応じてMATLAB／Octaveからパラメーターを設定します．
4. openMHAで `cmd=start` を実行します．
5. リアルタイム処理では，必要に応じてMATLAB／Octaveからパラメーターを変更します．
6. `cmd=stop` で停止，または `cmd=quit` で終了します．

付属のMATLAB／Octave関数内の値を編集して関数を実行すると，openMHAが要求する形式のパラメーターを計算し，TCP接続で実行中のopenMHAへ送信します．許容範囲外の値には修正すべき内容を示すエラーが出ます．設定ファイル自体を編集し，全体構造や信号の流れを変更することも可能です．

訳注：既定設定でのオフライン処理はMATLABなしで実行できます．このディレクトリをカレントディレクトリとして，次を実行します．

```sh
mha '?read:cfg/HSIM_files.cfg' cmd=start cmd=quit
```

既定の出力先は `HSIM_out.wav` です．入力・出力のパスはカレントディレクトリを基準に解決されます．

## アーキテクチャ

信号を周波数帯域に分割し，帯域別のレベル依存利得（ダイナミックレンジ拡張）で閾値上昇，補充現象，ダイナミックレンジ縮小を再現します．続いて帯域ごとのスペクトルスメアリングにより，蝸牛障害に伴う振幅の不確かさ，周波数選択性の低下，時間ジッターを再現します．これにより聴覚損失の減衰成分と歪み成分をモデル化します．各フレームの処理は次のとおりです．

1. ステレオの各チャンネルを時間領域の32帯域ガンマトーンフィルターバンクへ通します．合計64帯域です．
2. ダイナミックレンジ拡張の利得表に従い，各帯域へ周波数・レベル依存利得を乗算します．オージオグラムの閾値で閾値上昇を，最適快適レベル・不快レベルも用いて補充現象とダイナミックレンジ縮小をモデル化します．
3. 拡張後の各帯域信号に，互いに無相関な白色雑音を低域通過フィルターへ通したものを乗算します（Hülsmeierら，2020；Mourgelaら，2020）．遮断周波数は聴覚フィルターの広がり幅であるスメアリング幅に対応します．スメアリング係数は相対的な広がりを示し，係数1は正常聴覚の幅，すなわち追加の広がり幅0です．時間領域での乗算は周波数領域での畳み込みに対応するため，振幅の不確かさ・時間ジッターに加えて，フィルターの広帯域化による周波数選択性低下を導入します．
4. 各チャンネルの32帯域を加算し，2チャンネルの広帯域信号へ戻します．

## 再現できる特性

### 閾値上昇

入力オージオグラムの気導聴力閾値（HTL）から直接導入します．任意の周波数分解能で手動指定するか，Bisgaardら（2010）の標準オージオグラムを選択できます．値を補間して聴覚フィルターバンクの中心周波数へ対応付けます．比較用の正常聴覚も選択できます．その場合，入力信号は正常聴覚の閾値から不快レベルまでのダイナミックレンジに制限されますが，それ以外の変更はしません．

### 補充現象とダイナミックレンジ縮小

補充現象は，正常より急峻なラウドネス成長曲線です．拡張アルゴリズムの周波数別入出力特性から生じます．HTLから最適快適レベル（MCL）・不快レベル（UCL）を求める際は，Pascoe（1988）のデータに3次多項式を当てはめ，滑らかで単調な関数を作ります．値が既知ならMCL・UCLを直接指定できます．ISO 226:2023の閾値等ラウドネス曲線を用いてdB HLをdB SPLへ換算し，HTL・MCL・UCLを支点として成長曲線を定めます．HTL未満はノイズゲート，UCL超はリミッターとします．ダイナミックレンジ縮小もHTLとUCLの指定から直接生じます．

### 振幅の不確かさ

狭帯域白色雑音との乗算が時間包絡を変化させます．雑音帯域幅は正常聴覚フィルターの帯域幅と，聴覚損失に依存するスメアリング係数で決まります．各周波数で係数がHTLの関数になると仮定し，文献の測定結果（Glasberg & Moore，1986；Peters & Moore，1992）のうち1000 Hzのデータを一次近似の基礎として3次多項式を当てはめています．HTLが0 dB HL未満では係数を1.0に固定します．完全に受動的な蝸牛に相当する推定値（約3.8；Moore & Glasberg，2004）を上限とします．

### 周波数選択性低下と時間ジッター

狭帯域白色雑音との時間領域での乗算は周波数領域での畳み込みになり，聴覚フィルターが実質的に広がってスペクトル分解能が低下します（Baer & Moore，1993）．乗算雑音は時間ジッターも生み，ピッチ知覚を劣化させます．

より複雑な障害やリハビリテーションの場面では，汎用補聴器（例4）やCIボコーダー（例32）などと組み合わせられます．その際はopenMHA設定の作成・編集に関する知識が必要です．

## 制限

現時点では感音難聴の減衰・歪み成分のみをモデル化します（Plomp，1978）．伝音難聴と混合性難聴は将来の拡張候補です．これらでは気導・骨導閾値に有意な差があり，本モデルの拡張利得表では曲線の形をほぼ維持したまま，周波数に応じて入出力特性を右へ移すことに相当します．

また，現在は単耳の影響だけを扱います．両耳ラウドネス加算や歪み成分の両耳間相関など，両耳の影響は原理的にはモデル化可能ですが，まだ実装されていません．

## 用途と助成

用途には，正常聴覚者に聴覚損失をシミュレートして行う心理音響研究（音声明瞭度，ピッチ知覚，聴取努力，ラウドネス知覚など），聴覚学・言語療法の教育，啓発活動があります．

本研究はドイツ研究振興協会（DFG）のExcellence Strategy，EXC 2177/1，Project ID 390895286による助成を受けています．
