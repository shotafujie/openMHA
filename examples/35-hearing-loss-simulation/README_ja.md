# 35-hearing-loss-simulation: 難聴シミュレーション

> [English version](README.md)

このディレクトリには、openMHA による難聴シミュレーション用の2つの設定ファイルが含まれています。1つはライブ信号処理用、もう1つは音声ファイル処理用です。

両設定ファイルは使用前に確認し、必要に応じて変更してください。

信号は32のガンマトーン周波数帯域に分割され、各帯域にレベル依存のゲインを適用して難聴レベルシミュレーションを行い、その後スペクトルスメアリングで障害された蝸牛の低下した周波数選択性をシミュレートします。

## 使用前に必要な変更

**キャリブレーション**: 使用するマイクロフォンとヘッドフォンに合わせてシステムの校正が必要です。難聴シミュレーションは非線形でレベル依存であるため、これは重要です。パラメータ `mha.calib_in.peaklevel` と `mha.calib_out.peaklevel` を設定してください。詳細は設定ファイル内のヒントおよび openMHA キャリブレーションマニュアルを参照してください。

**ゲインテーブル**: 配布ファイルでは低周波の 30dB HL から高周波の 70dB HL への傾斜型難聴をシミュレートしています。希望する難聴をシミュレートするには、`mha.c.split_dc.c.dc.gtdata` で設定されているゲインテーブルを調整してください。

**スペクトルスメアリング**: `mha.c.split_smearing.s.*.lpfilt.*` と `mha.c.split_smearing.s.*.smeared.out` の設定を変更してください。詳細は設定ファイル内のコメントを参照。
