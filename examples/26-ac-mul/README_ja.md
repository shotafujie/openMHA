# 26-ac-mul: AC 乗算プラグイン

> [English version](README.txt)

このディレクトリには、`ac_mul` プラグインの使い方を実演する設定ファイルと入力音声ファイルが含まれています。

`ac_mul` プラグインの一般的な説明については、openMHA_plugins.pdf マニュアルの対応するセクションを参照してください。

| 設定ファイル | 説明 |
|---|---|
| `example-frequency-shift-updown.cfg` | 入力信号に正弦波を乗算し、アップシフトとダウンシフトされた入力信号のミックスを出力。周波数シフト量は乗算する正弦波の周波数に等しい。ファイル末尾に演習問題あり |

詳細については、設定ファイル内のコメントを参照してください。
