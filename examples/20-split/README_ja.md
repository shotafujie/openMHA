# 20-split: 信号分割処理

> [English version](README.txt)

このディレクトリには、split プラグインの使い方を示す2つのサンプルが含まれています。このプラグインはオーディオ信号を1つ以上のチャンネルのグループに分割し、並列に処理します。

主な用途は2つあります:

## 1) チャンネル選択的処理

チャンネルを選択的に処理する機能を持たないプラグインから一部のチャンネルを隠す場合に使用します。`split_simple.cfg` で実演されています。noise プラグインは入力のすべてのチャンネルにノイズを追加するため、一部のチャンネルにのみ選択的にノイズを追加することはできません。この設定ではステレオ信号を1チャンネルずつの2グループに分割し、一方のグループにのみノイズを追加し、もう一方はスルーします。

## 2) 計算の並列化

計算コストの高い処理を並列化する場合に使用します。`split_live_posix.cfg`（または `split_live_win32.cfg`）で実演されています。ライブ入出力を使用する場合、オーディオバッファあたりの処理時間に上限があります（リアルタイム処理）。デフォルトではすべてのオーディオ処理は単一スレッドで1つの CPU コアを使用します。split プラグインを使用すると追加スレッドを生成し、複数の CPU コアを並列に使用できます。
