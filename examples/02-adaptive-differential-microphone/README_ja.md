# 02-adaptive-differential-microphone: 適応差動マイクロフォン

> [English version](README.txt)

このディレクトリの設定ファイル `adm.cfg` は、プラグイン「adm」の使い方を実演します。このプラグインは、1つの補聴器デバイス上の2つの無指向性マイクロフォンを1つの適応差動マイクロフォンに統合します。

設定ファイルには詳細なコメントが記載されています。このアルゴリズムの詳細については、設定ファイル内のコメントを参照してください。

この設定はオーディオファイル処理を行います。このディレクトリ内の音声ファイル `1speaker_diffNoise_4ch.wav` を処理し、出力音声ファイル `1speaker_diffNoise_4ch_OUT.wav` を生成します。

出力音声ファイルは2チャンネルのみであることに注意してください。アルゴリズムが4入力チャンネルを2出力チャンネルに統合するためです。

処理は次のように開始します:

```
mha ?read:adm.cfg cmd=start cmd=quit
```
