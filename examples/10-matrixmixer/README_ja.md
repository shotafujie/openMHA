# 10-matrixmixer: マトリクスミキサー

> [English version](README.txt)

このディレクトリには、matrixmixer プラグインの使い方を実演する設定ファイルと入力音声ファイルが含まれています。

matrixmixer プラグインの一般的な説明については、openMHA_plugins.pdf マニュアルの対応するセクションを参照してください。

| 設定ファイル | 説明 |
|---|---|
| `example-stereo-to-mono-downmix.cfg` | ステレオ信号をモノラルにダウンミックスする方法の実演。ファイル末尾に演習問題あり |
| `example-source-panning.cfg` | 複数の音源を1つのステレオ信号にミックスし、個々の音源に異なる左右定位感を付与する方法の実演 |
| `example-karaoke-filter.cfg` | ステレオ音楽録音からボーカルを除去できるシンプルなカラオケフィルタの実演。ファイル末尾に演習問題あり |

詳細については、各設定ファイル内のコメントを参照してください。
