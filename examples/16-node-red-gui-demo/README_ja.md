# 16-node-red-gui-demo: Node-RED GUI デモ

> [English version](README.txt)

このディレクトリには、ライブオーディオ信号を処理しながら openMHA 設定のパラメータを変更でき、実行中の openMHA からモニタ変数を連続的に読み取れるグラフィカル制御インターフェースのトイサンプルが含まれています。

## 必要要件

GUI はフローベースプログラミングツール Node-RED に基づいています。実行にはシステムに Node-RED がインストールされている必要があります。詳細は https://nodered.org/ を参照してください。

また、Node-RED ダッシュボードノード（https://flows.nodered.org/node/node-red-dashboard）もインストールが必要です。

このサンプルは Linux 環境で開発・テストされています。以下の手順は Linux を前提としていますが、openMHA と Node-RED は複数のプラットフォームで利用可能なため、他の OS でも実行は可能です。

## 実行方法

この設定はマイクロフォン入力信号のライブ処理を行います。結果の信号はサウンドデバイスの出力チャンネルから出力されます。

openMHA 設定に合わせて JACK サーバーを起動する必要があります（fs=44100、64 frames/period）。

処理の開始:

```
mha ?read:node-red-gui-demo.cfg cmd=start
```

GUI の開始:

```
node-red GUI_demo.flow
```

Node-RED 設定インターフェース: http://127.0.0.1:1880/

openMHA 制御ダッシュボード: http://127.0.0.1:1880/ui/#!/0

## GUI 要素

### 左パネル
- **コンプレッサ設定**: 緑のドットを動かして出力信号の音響特性を変更。手動生成されたゲインテーブルのセットが使用されています。2Dパネルの中央、端、角の位置での特性の概要は `gaintables.pdf` を参照
- **ノイズ/正弦波ジェネレータ**: オン/オフ切替、レベル制御、正弦波の周波数設定

### 右パネル
- **広帯域入力レベル**: 左右マイクチャンネルの入力レベル測定。非校正セットアップのため、表示レベルは物理的な音圧レベルとは一致しません
- **コンプレッサ入力レベル**: 左右入力チャンネルのダイナミックレンジコンプレッサの各周波数帯域レベル。信号ジェネレータの寄与が観察可能
- **全体レベル**: 左右入力チャンネルの平均広帯域レベル
